# 🎵 Spotify Clone (Web Frontend)

A feature-rich, responsive frontend clone of **Spotify**, built using pure **HTML5** and **CSS3**. This project replicates the modern desktop user interface of Spotify, featuring a sticky navigation bar, sidebar layout, card grids for music categories, and a fully structured custom music player bar at the bottom.

---

## ✨ Features

* **Modern Layout & UI:** Replicates Spotify's distinct 3-panel layout (Sidebar, Main Content Area, and Music Player).
* **Responsive Design Elements:** Uses CSS Flexbox and modern selectors for clean alignment and scaling.
* **Interactive Controls:** Includes custom progress bars, volume ranges, hover effects, and Font Awesome control icons.
* **Card Grids:** Showcases "Recently Played", "Trending Now", and "Featured Charts" with hover states and cover images.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Variables, Custom Pseudo-elements for ranges)
* **Icons:** Font Awesome Free
* **Version Control:** Git & GitHub
